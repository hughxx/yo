CoreInsight LocalToolkit 前端接口（统一信封版）
Base URL: http://127.0.0.1:17831

统一响应：
所有成功接口的 HTTP status 均为 200。
成功响应：code=200，msg=ok，data=实际业务数据；前端统一从 data 取值。
错误响应：HTTP status 保留 409/422/426/502/500 等，code 与 HTTP status 相同，msg 为错误原因，data=null。
以下各接口所述“响应”均指信封中的 data 字段。

一、页面初始化

1. GET /health
时机：页面打开时首先调用，判断 LocalToolkit 是否启动。

2. GET /welink/cli/status
时机：/health 成功后调用，判断 welink-cli 是否安装且可用。
使用：ready=true 才允许预览消息和启动提取。

3. GET /welink/skill/list
时机：页面初始化时调用，填充 Skill 选择列表。

4. GET /welink/group/list
时机：页面初始化、添加/修改/删除群组、任务状态结束后调用，刷新群组配置和状态。

5. GET /welink/extract/tasks
时机：页面初始化时调用，恢复各群组未结束任务及近期任务状态。


二、群组管理

6. POST /welink/group/add
时机：用户添加群组时调用。
请求：
{
  "groupId": "群组ID",
  "name": "群组名称"
}

7. PUT /welink/group/update
时机：用户保存群组配置时调用。
使用：提交 GET /welink/group/list 返回的完整群组对象，修改其中的用户配置字段后整体提交。

8. DELETE /welink/group/delete
时机：用户删除群组时调用。
请求：
{
  "groupId": "群组ID"
}
使用：群组存在未结束任务时会返回 409，应先取消任务。


三、消息预览

9. POST /welink/message/page
时机：用户打开消息预览、刷新预览、点击“加载更早消息”时调用。
首次请求：
{
  "groupId": "群组ID",
  "startTime": "2026-08-10 00:00:00",
  "endTime": "2026-08-17 23:59:59",
  "cursor": "",
  "limit": 100
}
加载更早消息：把上一次响应的 nextCursor 传入 cursor。
停止条件：hasMore=false。
响应：
{
  "items": [],
  "nextCursor": "",
  "hasMore": false,
  "totalHint": 0
}
注意：totalHint 不能用来判断历史消息总数。


四、手动提取

10. POST /welink/extract
时机：用户点击“提取”时调用。
请求：
{
  "groupId": "群组ID",
  "startTime": "2026-08-10 00:00:00",
  "endTime": "2026-08-17 23:59:59",
  "skillId": "welink-experience-extractor",
  "extractMode": "direct",
  "uploadBy": "当前登录用户账号",
  "selection": {
    "mode": "all",
    "excludedMessageIds": [],
    "selectedMessageIds": []
  }
}
使用：保存响应中的 data.taskId，并立即开始查询该任务状态。
规则：同群组已有未结束任务时返回 409；其他群组的任务会正常进入 queued 队列。
规则：该群组已启用定时提取时，应先调用 /welink/schedule/cancel。

selection 用法：
全部提取：mode=all，用户取消勾选的 ID 放入 excludedMessageIds。
明确选择：mode=explicit，选中的 ID 放入 selectedMessageIds。
不传聊天正文，只传消息 ID 选择条件。

11. GET /welink/extract/status?taskId={taskId}
时机：POST /welink/extract 成功后轮询；建议每 2 秒调用一次。
停止条件：running=false。
结果判断：status=done 成功；status=failed 读取 error；status=cancelled 已取消；status=queued 正在排队。

12. GET /welink/extract/status?groupId={groupId}
时机：需要恢复或刷新某一个群组的最近任务状态时调用。

13. POST /welink/extract/cancel
时机：用户取消某个提取任务时调用。
推荐请求：
{
  "taskId": "任务ID"
}
没有 taskId 时也可以按群组：
{
  "groupId": "群组ID"
}


五、定时提取

14. POST /welink/schedule/set
时机：用户确认新增或修改定时提取配置时调用。
请求：
{
  "groupId": "群组ID",
  "uploadBy": "当前登录用户账号",
  "skillId": "welink-experience-extractor",
  "extractMode": "direct",
  "scheduleFreq": "daily",
  "scheduleTime": "09:00:00",
  "scheduleCron": ""
}
使用：scheduleFreq 支持 daily、weekly、monthly、custom；custom 时填写五段 Cron。
使用：同群组存在未结束任务时返回 409。

15. POST /welink/schedule/cancel
时机：用户点击“取消定时”，或手动提取前需要取消该群组定时时调用。
请求：
{
  "groupId": "群组ID"
}


六、统一处理

时间格式：YYYY-MM-DD HH:mm:ss。
POST /welink/extract 返回成功只表示任务已受理，不代表提取已完成。
403：当前网页 Origin 不在 LocalToolkit 白名单。
404：群组或任务不存在，或群组尚未绑定。
409：同群组任务或定时状态冲突。
422：请求字段或时间格式错误。
426：LocalToolkit 必须升级，停止继续调用 WeLink 业务接口。
502：welink-cli、Hermes、文件服务或下游调用失败。
