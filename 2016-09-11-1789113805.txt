scene/scene_id 接口变更

本文仅包含本次场景参数涉及的 4 个接口。


1. POST /email/extract

邮件手动提取。请求体新增：
{
  "scene": "邮件问题定位经验",
  "scene_id": "251"
}

完整请求示例：
{
  "folders": ["邮箱 - 用户\\收件箱"],
  "startTime": "2026-09-01 00:00:00",
  "endTime": "2026-09-11 23:59:59",
  "query": "",
  "matchedOnly": false,
  "skillId": "email-experience-extractor",
  "extractMode": "direct",
  "uploadBy": "当前登录用户账号",
  "scene": "邮件问题定位经验",
  "scene_id": "251",
  "selection": {
    "mode": "explicit",
    "selectedItemIds": ["Outlook EntryID"],
    "excludedItemIds": []
  }
}

  "scene_id": "251"
}

完整请求示例：

  "folders": ["邮箱 - 用户\\收件箱"],
  "uploadBy": "当前登录用户账号",
  "skillId": "email-experience-extractor",
  "extractMode": "direct",
  "scene": "邮件问题定位经验",
  "scene_id": "251",
  "scheduleFreq": "daily",
  "scheduleTime": "09:00:00",
  "scheduleCron": "",
  "since": "2026-09-01 00:00:00"
}


4. POST /welink/schedule/set

WeLink 定时增量提取。请求体新增：
{
  "scene": "WeLink问题定位经验",
  "scene_id": "251"
}

完整请求示例：
{
  "groupId": "群组ID",
  "uploadBy": "当前登录用户账号",
  "skillId": "welink-experience-extractor",
  "extractMode": "direct",
  "scene": "WeLink问题定位经验",
  "scene_id": "251",
  "scheduleFreq": "daily",
  "scheduleTime": "09:00:00",
  "scheduleCron": "",
  "since": "2026-09-01 00:00:00"
}


统一行为：

- scene 和 scene_id 都是字符串。
- 前端传入后，LocalToolkit 优先使用前端值，覆盖 Skill 输出中同名字段。
- 手动提取时，该值应用于本次产生的所有经验。
- 设置定时时，该值会持久化；后续每次定时触发都使用已保存的值。
- 正式入库 direct 和草稿 draft 模式均生效。
- 未传或传空字符串时，保留原有 Skill/默认场景逻辑。
