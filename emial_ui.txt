布局说明：
1. 左侧固定为 Outlook 状态和文件夹多选树；未选择文件夹时使用默认收件箱。
2. 右侧从上到下依次为顶部操作栏、时间范围、邮件列表和分页状态栏。
3. 页面初始化默认时间范围为最近 7 天；所有时间统一显示为 YYYY-MM-DD HH:mm:ss。
4. 邮件列表每页 50 封。跨页勾选需要保留，底部“已选”显示所有页面累计选择数。
5. “规则”列显示命中的提取规则；黑名单命中显示“已排除 · 规则名”。
6. 没有启用的提取规则时，在筛选区下方显示常驻红色警告框；“去配置规则”直接打开规则弹窗。
7. 警告文案固定为：“尚未配置提取规则。全量读取可能涉及隐私信息，请先配置提取规则。”
8. 首行严格参考 pyqt_client：搜索输入、规则过滤复选框和“按规则匹配”入口组成一个组合搜索框；右侧只有“刷新”和“启动”按钮。
9. 主页面不直接展示 Skill、入库方式和用户工号；点击提取或定时后再在弹窗中配置。
10. 点击“启动”显示下拉菜单：

    ┌──────────────────────────────────┐
    │ 提取选中                         │
    │ 当前选中 3 封邮件                │
    ├──────────────────────────────────┤
    │ 启动定时 / 修改定时              │
    │ 使用已保存的提取规则与黑名单      │
    └──────────────────────────────────┘

交互说明：
1. 点击列表中的“预览”打开；加载中显示“正在读取正文……”。

规则说明：
1. “提取规则”和“黑名单”使用相同字段结构，分两个页签维护。
2. 主题关键词、正文关键词、发件人均支持多个值，以逗号分隔。
3. 单个类别内多个关键词按“任一关键词命中”处理。
4. OR：主题、正文、发件人三类中任一已填写类别命中；AND：所有已填写类别都命中。
5. 筛选顺序：先判断提取规则，再判断黑名单；黑名单优先级更高。
6. 启用了至少一条提取规则时，手动筛选和定时任务均可按规则过滤邮件。
7. 没有启用的提取规则时，页面必须显示红框隐私警告，引导用户先配置规则；不得将全量提取表现为推荐默认行为。

定时语义：
1. since 只决定第一次扫描的起点。
2. 每次执行范围为“上次成功游标（不含）到本次触发时间（含）”。
3. Outlook 读取、Skill 提取和最终入库全部成功后，才把游标推进到本次触发时间。
4. 执行失败时保留旧游标，下次会重新覆盖尚未成功处理的时间段。
5. 定时任务不使用主页面的临时时间范围和手工勾选结果。


六、主要页面状态

1. Outlook 检测中
   左侧账号卡显示“正在检测……”，状态点为灰色；刷新邮件和提取按钮禁用。

2. Outlook 未就绪
   左侧账号卡显示错误原因，状态点为红色；页面保留配置能力，但不可读取或提取邮件。

3. Outlook 已就绪
   显示当前 Outlook 账号，状态点为绿色；允许刷新文件夹和邮件。

4. 未配置提取规则
   邮件筛选区下方显示红色边框、浅红背景的常驻警告；提供“去配置规则”入口，点击后打开规则弹窗。

5. 邮件加载中
   表格区域显示遮罩和转圈：“正在读取 Outlook 邮件……”。

6. 空列表
   首次进入显示“点击‘刷新邮件’读取本机 Outlook”；查询无结果时显示空状态。

7. 提取执行中
   底部状态显示当前阶段和进度；“提取选中邮件”变为“取消提取”，其他会冲突的操作禁用。

8. 提取成功
   底部显示处理邮件数、生成经验数；同时通过 WeLink 通知用户结果。

9. 提取失败或取消
   底部显示失败原因或已取消；保留当前邮件选择，方便用户重试。

10. 已启用定时
   底部显示下次执行时间和当前游标，同时展示“取消定时”按钮。


七、手动提取交互流程

进入页面
  → 检测 Outlook
  → 读取已保存配置、Skill、定时状态
  → 刷新文件夹
  → 检查提取规则；无启用规则时显示红框隐私提醒
  → 选择文件夹和时间范围
  → 刷新/搜索邮件
  → 跨页勾选邮件
  → 点击“提取选中邮件”
  → 在弹窗中选择 Skill、入库方式，确认用户工号
  → 保存当前配置并启动任务
  → 每 2 秒刷新任务状态
  → 成功后显示结果并发送 WeLink 通知

说明：前端只提交 Outlook 邮件 ID，不提交邮件正文或附件。正式提取时由 LocalToolkit 重新读取
邮件与附件，将 HTML 转成 Markdown；图片执行 OCR 并写成 ![OCR结果](公开URL)，其他附件写成
可访问链接，再交给 Skill 处理。


八、响应式要求

1. 宽屏：左侧文件夹栏约 240px，右侧自适应。
2. 中等屏幕：底部配置分两行，邮件表格可横向滚动。
3. 窄屏：左侧文件夹区移到邮件列表上方；表格保持最小宽度并横向滚动。
4. 弹窗最大宽度不超过视口的 95%，正文和规则列表内部滚动。
